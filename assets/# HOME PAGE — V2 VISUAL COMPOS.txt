# HOME PAGE — V2 VISUAL COMPOSITION REDESIGN

This is a **visual composition redesign**, NOT a content rewrite and NOT a website architecture redesign.

The current Home page business positioning and information architecture have already been approved.

Your job is to make the Home page **visually distinctive and substantially different from a generic AI-generated industrial B2B website**.

## 1. NON-NEGOTIABLE RULE

KEEP the existing Home page information architecture:

1. Hero
2. What We Do
3. Our Solutions
4. Current Product Focus
5. Evidence / Why Work With HM
6. Applications
7. Final CTA

Do NOT:

* create a new sitemap
* change navigation
* redesign other pages
* modify Solutions, Products, Quality, About, Support or Contact
* change shared Header/Footer
* rewrite the business positioning
* invent new services
* remove important approved content

The commercial logic stays the same.

Only the **visual composition, layout hierarchy and presentation** should change.

---

# 2. THIS IS NOT A STYLING PASS

IMPORTANT:

Do NOT simply:

* change colors
* change fonts
* change border radius
* change shadows
* change spacing
* make existing cards prettier
* add animations
* add gradients

That is NOT sufficient.

The current design already received a styling pass, but the page still feels structurally similar to a generic B2B template.

### The required change is:

**RECOMPOSE THE PAGE.**

At least **4 major sections must receive a fundamentally different layout composition**.

The user should be able to visually notice that the page has been redesigned even without reading the text.

The visual identity should communicate:

**TECHNICAL**
**ENGINEERING**
