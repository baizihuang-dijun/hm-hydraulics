# HM Hydraulics Website V3.1 — Final Content & UX Execution

## OBJECTIVE

Revise the existing HM Hydraulics website based on the structure and content below.

This is a **content hierarchy and visual density optimization**, not a complete redesign.

The previous version established the correct commercial positioning. This version must make the website:

* Less text-heavy
* Faster to scan
* More visually confident
* More commercially focused
* More technically credible
* Easier for an overseas OEM / engineering / purchasing manager to understand

Do NOT weaken the positioning or remove important capabilities.

The goal is:

> **Less explanation. More information density. More visual hierarchy.**

The website should feel like a strong industrial B2B company, not a brochure or business proposal.

---

# 1. CORE POSITIONING — DO NOT CHANGE

Primary positioning:

**Technical Sourcing Partner for Hydraulic Components**

Core promise:

**From Technical Requirement to Reliable Delivery.**

Three core capabilities:

**ENGINEERING → SUPPLY → DELIVERY**

Current primary product:

**Hydraulic Rotary Actuators**

Business model:

Customer Requirement
→ Engineering Support
→ Manufacturing Sourcing
→ Technical / Quality Validation
→ Supply Coordination
→ Delivery

HM is NOT positioned as a generic manufacturer.

HM should be understood as the company that manages the technical and supply process between the customer's requirement and qualified manufacturing capabilities.

---

# 2. GLOBAL CONTENT RULE

The previous version contains too much explanatory copy.

Apply this rule to every page:

### SHOW FIRST. EXPLAIN SECOND.

Prefer:

**Short headline + short explanation + visual/card/data**

Avoid:

**Long headline + paragraph + second paragraph + multiple supporting paragraphs**

General rule:

* Most supporting text should be 1–2 sentences.
* Do not explain the same concept twice.
* Do not repeat the same value proposition throughout every section.
* Do not use a paragraph when a short phrase will communicate the idea.
* Use numbers, cards, labels and visual structure wherever possible.
* Preserve commercial meaning while aggressively removing repetition.

The website should be easy to scan without reading every word.

---

Home's job is:

**Positioning → How We Help → Core Capabilities → Product Entry → Evidence → CTA**

The final Home page should contain ONLY these 7 sections:

1. Hero

Remove or merge any other Home sections that duplicate these messages.

After implementation, review the entire website as if you are:

**A purchasing manager at a US / European OEM who has never heard of HM Hydraulics.**

Within 10–20 seconds, the visitor should understand:

1. HM works with hydraulic components.
2. HM is a technical sourcing partner.
3. HM can help with engineering / selection / customization.
4. HM can coordinate manufacturing and quality.
5. HM can coordinate delivery.
6. Rotary actuators are the current core product.
7. The customer can send an existing part, drawing or requirement.
